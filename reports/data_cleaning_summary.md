## 4. Chronological Ordering, Timestamp Ties & Ambiguities

### 4.1 Timestamp Granularity & Same-Case Ties
- Source timestamps are recorded with 1-minute precision (`%Y-%m-%d %H:%M:00`).
- **Same-case timestamp ties:** Exactly **22,024 events (15.41% of all events)** occur at the exact same minute as another event in the same case.
- **Typical Tie Causes:**
  1. Instantaneous order generation: Physician registers patient check-in and issues prescription within the same minute.
  2. Batch specimen collection: Multiple blood tubes drawn simultaneously at 14:30 for distinct panels (CBC + Metabolic Panel).
  3. Short imaging exams starting and finishing in $<60$ seconds.

### 4.2 Deterministic Ordering Implementation
To ensure reproducibility across process mining engines without introducing false race conditions, events are sorted by:
$$\text{case\_id} \longrightarrow \text{timestamp} \longrightarrow \text{stage\_order} \longrightarrow \text{source\_order\_id}$$
Where `stage_order` enforces clinical domain sequencing:
1. `Appointment`
2. `Prescription`
3. `Laboratory Start`
4. `Laboratory End`
5. `Imaging Start`
6. `Imaging End`
7. `Pharmacy Start`
8. `Pharmacy End`

> [!IMPORTANT]
> **Process Mining Caveat:** While the event log is deterministically sorted, the true chronological sequence between tied events cannot be determined by timestamps alone. Process discovery algorithms should treat coincident events as potentially concurrent or parallel.

## 6. Remaining Data Quality Limitations

1. **Unresolved Laboratory Turnaround Times for 4,702 Tests:** Because 26.08% of lab end records possess truncated `MM:SS.f` strings, these tests only have a `Laboratory Start` event. Their turnaround time and completion event cannot be analyzed in process mining without explicit LIS database re-export.
2. **Minute-Level Clock Coarseness:** With 15.41% of events sharing timestamps, sub-minute operational lead times (e.g., consultation-to-prescription delay) cannot be measured when both occur within the same minute.
3. **Prescription End Datetimes Excluded:** Because 66.52% of prescriptions have zero duration ($Start == End$) and 52 records have negative durations ($End < Start$), prescription authoring is modeled strictly as a point event.
4. **Pre-Appointment Lab Draws:** In 457 encounters (2.53% of lab visits), specimen collection occurred before appointment check-in. Process mining discovery models will show a small variant branch where laboratory precedes appointment start.
